## 주요 기능

- **소울 루프** : 사망 시 영혼 드랍, 회수, 화톳불 휴식/세이브, 적 리스폰
- **전투 시스템** : 공격, 가드/패리/가드 브레이크, 회피, 락온
- **타격감** : 히트스톱, 카메라 셰이크, 히트 플래시, 피격 비네트, 동작 동기화 사운드
- **다양한 적 (FSM)** : 근접 / 원거리 / 엘리트 / 보스
- **보스전** : 다단계 공격 패턴, HP 50% 페이즈 전환
- **장비 시스템** : 인벤토리 / 상점 / 장비 착용 + 무기·방패 비주얼 연동
- **데이터 주도 설계** : 적/아이템/사운드를 ScriptableObject로 관리
